# 诊断与扫描规程

本文件区分可复用操作与单次研究结论；不启动任何训练或后续方法。

1. **先写门，再看数据。** `../evidence/decision.md` 中 M2>=0.005、
   M4>=0.05、M5>=0.2 是具体实验的判定门；逐 checkpoint 判定。
   gwrp 通过三门，另两组未通过交集门。不能统一概括为全部 NO-GO，
   也没有日志证明“省下两周”。新场景须重新预注册，不继承阈值有效性。
2. **图像是重采样单位。** 每图多个正类、patch 和类对是相关观测。
   先在图像内归约再 bootstrap，或重采样整图 confusion 后计算全局指标。
   两种估计量不得互换，图像 CI 不包含训练 seed 不确定性。
3. **跨模型符号复现不是多重比较校正。**
   `../evidence/Head_Alpha_Execution_Notes.md` 明确同格正号仍不校正网格
   多重比较。探索性最优值需标注，不宣称可以代替 Bonferroni。
4. **选参和报告分离。** 同一来源的 alpha 实验固定分折，另一折报告，
   bootstrap 在折内重采样并重新选参。可共享推理，统计处理仍有计算成本。
   原生读出和带 epsilon 的对照需要同时保留，避免把 clamp 差异归因于参数。
5. **逐值等价后再替换接口。** 本包用固定种子 FP32 合成输入同时调用原实现，
   atol=1e-7、rtol=0、缺失值位置相同；失败即停，不放宽容差。
   通过合成 parity 不等于在新模型或新数据上已经验证有效。
6. **推理先导与训练结论分开。**
   `../evidence/AFFINITY_SCREENING_REPORT.md` 是 frozen inference；
   `stage_b_comparison.csv` 是不同的训练结果。共享每图前向可以节省扫描成本，
   配置内矩阵运算仍有成本，不保证配置数量“几乎免费”。
7. **无标签选择和 oracle 分列。** Head/alpha 来源的 kappa/gamma 排序不读
   segmentation masks；若以后使用 GT 选参数，只能报告为 oracle。
8. **负结果仍要可审计。** 记录门、未舍入值、CI、命令和数据哈希，不能用
   True/False 取代科学判断。A2 的程序门 True 与跨零 CI 均原样归档。
   规格中的 A1 熵 `0.99999` 未在本次选定证据中核实，不当成黄金值引用。

低精度转 FP32 无法恢复先前丢失的信息。探针须恢复模块 training 标志、
RNG 和 TF32，并且不在原模型上就地改变参数 dtype。
